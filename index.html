        Vercel 官方教程
        
          
          
          
          自己在 GitHub 部署单个 HTML
          适合资源已经包含在文件里的单页网页。GitHub 网页上传单文件上限为 25 MiB；更大的网页或多文件 ZIP 请用快捷部署。
          1. 把网页命名为 index.html
            iOS 在“文件”App 中长按文件 → 重新命名；安卓在文件管理器中重命名。确认后缀是 .html。
          2. 登录并新建仓库
            打开 GitHub 网页，点菜单里的 New repository。填写仓库名称，选择 Public，再点 Create repository。
          3. 上传网页文件
            空仓库点 uploading an existing file；已有初始文件的仓库点 Add file → Upload files。点 choose your files，选择 index.html，再点 Commit changes。
          4. 开启 Pages
            进入仓库 Settings → Pages。在 Source 选择 Deploy from a branch，选择存放网页的分支（常见为 main）、/(root)，再点 Save。
          5. 打开网站
            等待 Pages 显示网站地址或 Visit site，点击打开。仓库地址是代码页面，Pages 地址才是你的网站。
          手机上找不到 Settings 时，先展开仓库顶部的更多菜单；仍找不到可在浏览器菜单中切换到桌面网站。
          
          
          文件、网址或发布遇到问题
          ZIP 应该放什么？
          放已经能直接打开的网页、图片、CSS 和 JS，保持相对目录。不要放 node_modules；需要 npm build 的源码请先生成 dist / build，再打包成 ZIP。
          为什么网址还是 404？
          发布需要等待。先检查仓库 Settings → Pages 的状态，再确认首页是 index.html。工具会显示“等待发布”，可以稍后重新检查。
          网页打开了，图片却没显示？
          检查是否漏打包图片，以及文件名大小写。项目网站通常带仓库名路径，资源建议使用相对路径。
          提示名称被占用或权限不足？
          换一个仓库名；权限不足时重新连接账号，确认令牌有建仓库、上传和 Pages 权限。
